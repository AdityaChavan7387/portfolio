01 / Project

GeoLedger — Blockchain-Based Land Registry

GeoLedger is a decentralized land ownership and registry system built on the Ethereum blockchain. It ensures tamper-proof, transparent land ownership records and enables secure peer-to-peer land transfers without the need for centralized authority. The platform uses smart contracts to automate ownership verification and transfer logic.

Key Highlights

Blockchain-backed immutable ownership records using Solidity smart contracts
Secure and transparent land transfer workflow via Web3.py integration
React frontend for user-friendly land search, registration, and transfer
Local blockchain simulation using Truffle & Ganache for development and testing
Flask backend REST API bridging the frontend and blockchain layer

Tech Stack

SolidityTruffleGanache FlaskReactWeb3.py

02 / Project

Image Encryption & Decryption

A Python-based project implementing XOR bitwise encryption to encrypt and decrypt image files. The project demonstrates applied cryptography concepts — ensuring data integrity and secure transmission of image data without relying on heavy libraries.

Key Highlights

XOR-based symmetric encryption algorithm applied to raw image pixel data
Supports lossless encryption and decryption with an identical key
Demonstrates core concepts of data confidentiality and integrity
Lightweight implementation with no external cryptography dependencies

Tech Stack

Python
